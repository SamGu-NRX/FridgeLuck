Your taste

The whole learning system in one readable page: sentences the app would say out loud, each with the count it is based on and a Right / Wrong control. No sliders, no percentages, no "personality" labels.

Three row states. Default: Right / Wrong. Confirmed: the Right button is held in yolk-soft and the row says when, in the same words the app will act on ("Never suggested"). Rejected: the row dims, the sentence is struck through, and "Won't use this" sits next to Undo. Nothing is deleted on Wrong; it is excluded from recommendations and kept so the app does not re-learn it next week.

"Never suggest" is the only list the user writes directly. Allergies from setup appear here too, labelled, and cannot be removed from this page (they are edited in setup).

"LeChef remembers" is the cook-complete notes, verbatim, with Forget per line. These are the lines LeChef reads back mid-cook.

States

new
Fewer than 3 cooks: the "What I've noticed" section is one sentence, "Cook three things and I'll start writing this." Setup answers and Never suggest still show.
thin
3 to 9 cooks: sentences use hedged language ("You seem to…") and counts; the fish row and the repeat row do not appear until 10 cooks.
loading
None. The profile is on device.
error
None for reading. If a Right / Wrong fails to persist, the control reverts and a one-line "Didn't save. Try again." appears under the row.
question pending
A pattern the app has asked about on Tonight but the user has not answered shows here with the two buttons highlighted by a yolk square at the leading edge.
forget all
Confirmation sheet: "Forget 23 cooks of learning? Setup answers and allergies stay." Forget / Keep. On Forget, the page returns to the "new" state.
export
Share sheet with a JSON of sentences, counts, source cook IDs, notes and setup answers.

Motion

right/wrong
Button fill crossfades 150 ms, light haptic. On Wrong the row opacity drops to 0.55 over 150 ms; no height change, no removal.
undo
Same crossfade back. Nothing bounces.
forget line
Row slides out with the settle spring and the list closes the gap with a transition.
