# Food-safety fix lists

Generated by `fl-safety-lint` against the named branches' heads. One file per
reviewed PR, named `<pr-number>-<slug>.md`. Each file lists every finding with
the canonical fix: file, record id, field, current text, required change, rule
id, citation.

Method: the CLI ran in the canon task's sandbox against a checkout of the branch
head recorded in the file. Findings are reproducible with the command shown at
the top of each file. This task never modifies another task's branch; owners
apply the fixes on their own branches.
