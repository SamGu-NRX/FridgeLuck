# FridgeLuck visual round

Three directions render the same screens side by side; Sam picks one (SPEC 5, PLAN Round 1).

- `direction-p/` — Direction P: Sam's approved pastel palette (Apps/ios AppTheme light + "Twilight Warmth" dark) kept as the colour base; layout, hierarchy, density, type and motion rebuilt to the SPEC 5 craft bar.
- `direction-f/` — Direction F: the prep list (`inputs/design-direction.md`): paper/hob, SF Pro + SF Mono, one yolk accent, flat with hairlines.
- `direction-h/` — Direction H: the hybrid of what works in each, documented per element.

Every direction renders: Tonight, Kitchen, scan review, recipe, cook mode (LeChef), taste profile, Explore, Table — light + dark, cook palette for cook mode — plus Tonight at accessibility XXL Dynamic Type, Sam's Shell S (Kitchen + Progress tabs, central scan orb, Profile inside Progress), and his candidates: light quests/badges (rewarding cooks made and food saved) and a constrained guided tour (3 steps, auto-return to Home, back button).
